Práctica 1, Parte 1

1. Abre esta carpeta en Visual Studio Code.
2. Selecciona un intérprete de Python 3.
3. Ejecuta comprobar_entorno.py.
4. Cuando aparezca "Entorno preparado", abre scipy-1.py.

Si falta algún paquete, instala las dependencias en el intérprete seleccionado:

python -m pip install -r requirements.txt

En Windows también puede ser necesario usar:

py -m pip install -r requirements.txt
